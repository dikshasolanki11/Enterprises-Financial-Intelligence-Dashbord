# 📊 Enterprise Financial Intelligence Dashboard | Power BI

## 📌 Project Overview

The **Enterprise Financial Intelligence Dashboard** is an interactive financial analytics project developed using Microsoft Power BI. The dashboard transforms financial data into meaningful business insights, helping management monitor financial performance, track profitability, analyze budgets, and make data-driven decisions.

The project focuses on financial reporting, KPI monitoring, departmental performance, and scenario-based forecasting.

## 🎯 Project Objectives

- Analyze overall financial performance and profitability.
- Track key financial metrics such as Revenue, COGS, Gross Profit, EBITDA, and Net Profit.
- Compare actual financial performance against budgets.
- Analyze cash flow, capital expenditure, and department-level performance.
- Develop interactive financial reports for management.
- Perform What-If Analysis to evaluate different business scenarios.

## 🛠️ Tools & Technologies

- **Microsoft Power BI:** Data visualization and dashboard development
- **Power Query:** Data cleaning and transformation
- **DAX:** Financial calculations and KPI measures
- **Data Modeling:** Star schema and table relationships
- **CSV Files:** Financial data sources

## 📂 Dataset Description

The project uses multiple financial datasets:

| Dataset | Description |
|---|---|
| Fact_GL_Transactions | General ledger financial transactions |
| Dim_Account | Account classifications and financial categories |
| Dim_Date | Date dimension for time-based analysis |
| Fact_Budget | Budgeted financial data |
| Fact_CashFlow | Cash inflows and outflows |
| Fact_CapEx | Capital expenditure information |
| Fact_Headcount | Employee headcount data |

- Operating Expenses
- EBITDA
- Net Profit
- Other Income
- Interest Expenses
- Tax Expenses

- Operating Margin %
- Net Profit Margin %
- Budget and Budget Variance
- Budget Variance %
- Free Cash Flow
- Revenue Growth %

## 📊 Dashboard Features

### 1. Executive Summary Dashboard
Provides a high-level overview of financial performance using KPI cards and interactive visualizations.

### 2. Financial Performance Analysis
Analyzes revenue, expenses, profitability, and financial trends across different periods.

### 3. Dynamic Profit & Loss Statement
Displays an interactive P&L statement using Power BI Matrix visuals and DAX measures.

### 4. Budget vs. Actual Analysis
Compares planned budgets with actual financial performance to identify positive and negative variances.

### 5. Department Performance Analysis
Evaluates departmental financial performance to support cost monitoring and resource allocation.

### 6. Scenario & Forecasting Analysis
Uses What-If parameters to simulate changes in revenue and analyze their potential financial impact.

## 🔄 Project Workflow

1. **Data Collection:** Imported financial datasets into Power BI.
2. **Data Cleaning:** Used Power Query to clean and transform data.
3. **Data Modeling:** Created a star schema with relationships between dimension and fact tables.
4. **DAX Calculations:** Developed financial KPIs and analytical measures.
5. **Dashboard Development:** Created interactive reports using KPI cards, line charts, bar charts, donut charts, waterfall charts, and matrices.
6. **Financial Analysis:** Evaluated profitability, budgets, cash flow, and departmental performance.
